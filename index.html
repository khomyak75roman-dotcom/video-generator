Готове відео
з одного запиту

Введіть тему — застосунок сам підбере відкриті відео-кліпи, озвучить текст українською, згенерує субтитри та зіб’є готовий MP4. Встановлюється одним клацанням.

⬇ Завантажити інсталятор 💻 Код на GitHub

Windows 10/11 · ~64 МБ · VideoGenerator-Setup.exe

Що вміє генератор

Усе, що потрібно для короткого відео — в одному вікні, без складних налаштувань.

🎙️

Українська озвучка

Природний голос через edge-tts — текст вашого запиту читається вголос.

🖼️

Відео-кліпи з Openverse

Застосунок сам шукає відкриті відео-кліпи за темою (Creative Commons) — ключі не потрібні.

🎬

Живий відеоряд

Кліпи монтуються один за одним у єдине відео; якщо кліпів мало — фото з наїжджанням камери.

💬

Субтитри SRT

Слова з’являються синхронно з голосом; окремий .srt-файл іде в комплекті.

📋

Вставка з буфера

Скопіюйте текст звідусіль і вставте однією кнопкою прямо у поле запиту.

🔓

Нуль API-ключів

Жодних реєстрацій і токенів. Встановив — і генеруєш. Повністю open-source.

Як це працює

Чотири кроки — від запиту до готового MP4 на диску.

Введіть запит

Тема відео своїми словами — поле приймає і скопійований текст.

Генератор працює

Озвучка, пошук кліпів, субтитри та рендер — усе автоматично, у журналі видно хід.

Готове відео

MP4 з озвучкою, живим відеорядом і субтитрами зберігається у вибрану папку.

Збірка прозора

Кожен коміт збирає новий інсталятор на GitHub Actions — збірка сама себе тестує.
