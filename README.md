# 🎬 VideoGenerator — готове відео з одного запиту

Безкоштовний десктопний генератор відео для **Windows**: впиши тему (або встав свій сценарій) — застосунок сам напише текст, озвучить його українською, підбере фонові кліпи, згенерує субтитри та зіллє готовий MP4.

**Жодних API-ключів, реєстрацій, підписок і хмарних сервісів.** Установив — і генеруєш.

## ⬇️ Встановлення

1. Завантаж `VideoGenerator-Setup.exe` зі сторінки [Releases](https://github.com/khomyak75roman-dotcom/video-generator/releases/latest).
2. Запусти інсталятор — далі, далі, готово. Windows 10/11.
3. Перший запуск: якщо на компʼютері нема ffmpeg чи yt-dlp, програма сама їх докачає (один раз, з офіційних джерел).

## ✨ Що вміє

- **Тема або сценарій** — одне поле: впиши тему своїми словами або встав готовий текст.
- **Українська озвучка** — природні голоси (Остап, Поліна + англійська, польська, німецька).
- **Живий фон** — відкриті відео-кліпи за змістом кожної частини (YouTube-пошук, Openverse, Wikimedia), фото з анімацією камери, AI-кадри.
- **Субтитри** — вбудовані у відео + окремий .srt-файл.
- **Бонуси** — обкладинка відео, переклад субтитрів іншою мовою, аватар-ведучий (фото + твій голос).
- **Resume** — впала генерація? Продовжить з того ж місця, нічого не перерахбовує.
- **Чесна ціна** — перед стартом показує орієнтовний час роботи, а кожен запасний режим пише у журнал.
